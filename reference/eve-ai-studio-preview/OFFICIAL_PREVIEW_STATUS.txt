OTTIMIZZAZIONE DELLA PREVIEW GITHUB

La libreria sorgente completa v1.2.2 rimane il riferimento autorevole.
Per evitare di inserire nel repository l’intero archivio da circa 143 MB,
l’anteprima GitHub utilizza copie animate ottimizzate esclusivamente per la
galleria:

- risoluzione runtime: 40 × 40;
- massimo 2 fotogrammi campionati per asset;
- formato WebP animato;
- metadati originali mantenuti;
- un solo asset visualizzato alla volta.

Le copie ottimizzate non sostituiscono i file sorgente e non devono essere
riutilizzate come master di produzione.
