Il workflow:

1. rigenera lo standalone dalla preview modulare;
2. impedisce dipendenze CSS o JavaScript esterne nello standalone;
3. apre la preview modulare tramite server locale;
4. apre lo standalone tramite file://;
5. verifica tutti i 64 asset, dimensioni e SHA-256;
6. verifica la galleria con 64 schede;
7. prova materiali, retrieval, chat RAG e apertura fonte;
8. salva il rapporto autorevole in:

   eve-ai-studio/checkpoints/EVE_HQ_FINAL_VERIFICATION.json
